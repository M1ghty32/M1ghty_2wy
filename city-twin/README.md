# 四川吉利学院 · 校园数字孪生 Demo

一个单文件 Three.js 数字孪生演示：严格按学校官方可视化位置服务平台的楼栋数据重建校园，叠加六张城市生命线网络与夜间指挥中心界面。

- 当前主页 `/city-twin/`：v2 真实底图版，使用官方 MVT 矢量瓦片（建筑/道路/水系/树木）
- 六网完整交互版：`/city-twin/v1/`（六网、事故、演示、设施搜索等）
- 入口：`index.html`（v2）/ `v1/index.html`（v1）
- Three.js r160.1 与全部 addons 已本地 vendored 到 `vendor/`，**无 CDN 依赖**，可离线运行
- 无后端、无构建步骤，数据全部在浏览器本地模拟

## 数据从哪来

| 数据 | 来源 |
| --- | --- |
| 51 栋楼栋轮廓、层高、类型、名称 | 学校官方「可视化位置服务平台」`map.guc.edu.cn` 的三维要素接口（GeoJSON），按 0.7m 精度简化后内嵌到页面 |
| 楼栋相对位置 | 官方经纬度按校园中心做等距投影，单位为米 |
| 道路、广场、绿化 | 官方平台未暴露矢量路网（底图是烘焙的斜视栅格），按楼栋关系与官方地图走向近似重建，**不是测绘数据** |
| 六网设施、事故脚本、KPI | 本地模拟，用于演示监测与处置流程 |

官方地图：<https://map.guc.edu.cn/#/>

## v2 重构：真实校园底图

官方二维地图使用的是一套 MVT 矢量瓦片：`/cmgis-server/map/v3/data/mvt/outdoor/1/{z}/{x}/{y}.mvt`。瓦片里包含真实的建筑轮廓、道路中心线、水系与树木点位，且带 `name` / `height` / `building` 属性。

v2 预览：<https://wangweiye.top/city-twin/v2/>

- 数据：`data/campus-v2.json`，51 栋建筑 / 160 条道路 / 8 片水系 / 72 个树木点位
- 场景：中央湖、环路、南门、图书馆、行政楼、体育馆、游泳馆、运动场、宿舍区全部按真实位置生成
- 说明：v1 使用的官方三维 GeoJSON 与真实底图存在约 30° 旋转与数百米平移，因此 v1 的道路与校门是近似；v2 改为直接使用矢量瓦片坐标

## 数据说明

- **v2 的楼栋、道路、水系来自官方二维矢量瓦片**，与官方地图逐段一致。
- v1 的楼栋来自官方三维 GeoJSON，但其坐标系与二维底图存在旋转/平移，v1 的道路、广场为近似补建。
- 实拍照片参考学校官网（图书馆立面、南门草坪装置），仅用于还原外观，不改变位置数据。

## 技术要点

- Three.js r160.1 + `EffectComposer` / `UnrealBloomPass` / `OutputPass`
- 楼栋轮廓用 `ExtrudeGeometry` 挤出，全部合并为单次 draw call
- 窗户由 `onBeforeCompile` 注入的着色器按世界坐标程序化生成
- 道路用 CatmullRom 曲线生成带状网格（车道 + 人行道 + 发光边线）
- 树木与路灯使用 InstancedMesh；阴影使用方向光 + PCFSoft ShadowMap
- 建筑入口雨棚、停车场与车辆、长椅、南门旗阵作为近景细节合并进场景
- `CSS2DRenderer` 渲染 HTML 标签；移动端面板为可展开抽屉

## 数据与隐私

所有 KPI、趋势、告警与事故脚本均为本地生成的演示数据，不代表真实校区运行状态；页面不发送任何数据。
