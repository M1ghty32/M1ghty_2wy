# 四川吉利学院 · 校园数字孪生 Demo

一个单文件 Three.js 数字孪生演示：8×8 街区校园、六张城市生命线网络、夜间指挥中心界面。

- 入口：`index.html`（单文件，含全部 HTML / CSS / JS）
- Three.js 通过 CDN（jsDelivr，r160.1）加载，首次打开需要联网
- 无后端、无构建步骤，数据全部在浏览器本地模拟

## 快速开始

```bash
# 任选一种本地静态服务器
python -m http.server 4180
# 打开 http://127.0.0.1:4180/city-twin/
```

直接双击 `index.html` 时，浏览器可能因 ES Module / importmap 的 file:// 限制而无法加载，建议用上面的本地服务器。

## 功能

| 模块 | 说明 |
| --- | --- |
| 校园场景 | 8×8 街区路网、程序化楼宇、窗口灯光、树木路灯、图书馆/体育馆/田径场/北湖/校门等地标 |
| 六张网 | 供水、电力、算力、通信、地下管廊、物流；每张网有独立设施、管线与流动粒子 |
| 左侧图层 | 六网显示开关；建筑体块、路网、名称标签、地下管廊 X-RAY 透视 |
| 右侧面板 | 总览（健康度、在线设施、告警、六网负载）；单网详情（KPI、90 秒趋势、设施清单、事故演练） |
| 底部 | 六网流速条 + 流速倍速滑杆；实时事件日志 |
| 交互 | 点击图层聚焦并飞镜头、悬停设施弹出读数、点击设施聚焦、X-RAY 地下透视、日夜切换、自动巡游 |
| 事故演练 | 每张网一个脚本化事故：告警 → 自动处置 → 恢复，同步更新 KPI、状态、日志与相机 |

## 技术要点

- Three.js r160.1 + `EffectComposer` / `UnrealBloomPass` / `OutputPass`
- 建筑体块合并为单次 draw call（`mergeGeometries`），窗户由 `onBeforeCompile` 注入的着色器按世界坐标程序化生成
- 设施信标抬升到建筑屋顶以上，避免被楼体遮挡；聚焦单网时只显示该网信标，保留其它网管线作为背景
- 管线粒子沿预采样曲线运动，流速倍率实时可调
- `CSS2DRenderer` 渲染 HTML 标签，随距离保持清晰

## 数据与隐私

所有 KPI、趋势、告警与事故脚本均为本地生成的演示数据，不代表真实校区运行状态；页面不发送任何数据。
