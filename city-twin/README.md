# 四川吉利学院 · 校园数字孪生 Demo

基于学校官方 MVT 矢量数据、Blender 与 Godot 的校园三维演示。

- 地图总览 `/city-twin/`：官方矢量底图与校园图层
- 校园漫游 `/city-twin/game/`：**Godot Web 版**，含第三人称与自由视角
- 旧版漫游 `/city-twin/legacy-three/`：保留的 Three.js 版本
- 离线引擎工程：`godot/`；程序化建模脚本：`blender/campus_final.py`

## 当前场景内容

- 60 栋建筑、210 条道路、8 片水系、真实树木点位和地表矢量面
- 墙面 / 屋顶分离，逐层逐开间窗洞与窗框、楼板线脚、阳台、入口雨棚
- 图书馆红砖立面体块、校门、湖岸、路灯、长椅和停车位
- 田径场 6 条跑道、足球门、4 片篮球场与 2 片网球场
- 草地 / 沥青 / 混凝土采用世界坐标三平面贴图，不依赖 GLB UV
- 带服装纹理与 Idle / Walk / Run 动画的骨骼人物
- 60 栋楼碰撞、第三人称相机避障，M 键全图自由环绕、平移和缩放

## 构建与运行

```powershell
# 生成校园 GLB（需要 Blender 5.x）
blender -b --python city-twin/blender/campus_final.py

# 打开 Godot 工程
godot --path city-twin/godot

# 导出 Web（需安装对应版本 Web 导出模板）
godot --headless --path city-twin/godot --export-release Web city-twin/game/index.html
```

`game/` 内为可静态托管的 Godot Web 构建，使用单线程导出，无需 COOP / COEP 特殊响应头。

## v2 重构：真实校园底图

官方二维地图使用的是一套 MVT 矢量瓦片：`/cmgis-server/map/v3/data/mvt/outdoor/1/{z}/{x}/{y}.mvt`。瓦片里包含真实的建筑轮廓、道路中心线、水系与树木点位，且带 `name` / `height` / `building` 属性。

当前主页：<https://wangweiye.top/city-twin/>
游戏模式：<https://wangweiye.top/city-twin/game/>

- 数据：`data/campus-v2.json`，60 栋建筑 / 210 条道路 / 8 片水系 / 72 个树木点位 / 479 个停车点 / 1,112 个运动区矢量面
- 场景：参考官方浅色二维总览，以矢量坐标绘制草地、湖面、灰色分级路网、步行路径、建筑和运动场；建筑多环保留内院，运动场与停车点由矢量设施数据生成
- 说明：v1 使用的官方三维 GeoJSON 与真实底图存在约 30° 旋转与数百米平移，因此 v1 的道路与校门是近似；v2 改为直接使用矢量瓦片坐标

## 数据说明

- **v2 的楼栋、道路、水系来自官方二维矢量瓦片**；运动场轮廓、停车点和树木点位使用同一套校园平面坐标。
- 道路、草地与设施按矢量几何生成；官方 2D 总览作为浅色样式与主要空间关系参考，非矢量化的铺装细节仍属近似表达。
- v1 的楼栋来自官方三维 GeoJSON，但其坐标系与二维底图存在旋转/平移，v1 的道路、广场为近似补建。
- 实拍照片参考学校官网（图书馆立面、南门草坪装置），仅用于还原外观，不改变位置数据。

## 技术要点

- Three.js r160.1 + `EffectComposer` / `UnrealBloomPass` / `OutputPass`
- 楼栋轮廓用 `ExtrudeGeometry` 挤出，全部合并为单次 draw call
- 窗户由 `onBeforeCompile` 注入的着色器按世界坐标程序化生成
- 道路用 CatmullRom 曲线生成带状网格（车道 + 人行道 + 发光边线）
- 树木与路灯使用 InstancedMesh；阴影使用方向光 + PCFSoft ShadowMap
- 建筑入口雨棚、停车场与车辆、长椅、南门旗阵作为近景细节合并进场景
- `CSS2DRenderer` 渲染 HTML 标签；移动端面板为可展开抽屉

## 数据与隐私

所有 KPI、趋势、告警与事故脚本均为本地生成的演示数据，不代表真实校区运行状态；页面不发送任何数据。
